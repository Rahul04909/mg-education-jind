🗄️  DATABASE STRUCTURE

Database: mg_skill
│
├── 📊 smtp_settings
│   ├─ id (PRIMARY KEY)
│   ├─ smtp_host
│   ├─ smtp_port
│   ├─ smtp_username
│   ├─ smtp_password
│   ├─ smtp_encryption (tls/ssl/none)
│   ├─ from_email
│   ├─ from_name
│   ├─ is_active
│   ├─ created_at
│   └─ updated_at
│
└── 📊 email_logs
    ├─ id (PRIMARY KEY)
    ├─ to_email
    ├─ subject
    ├─ message
    ├─ status (success/failed)
    ├─ error_message
    └─ sent_at
    
    Indexes:
    ├─ idx_status
    └─ idx_sent_at
